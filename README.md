### 1. 用户研究主线：接触、能力、改善认知及其闭环运用

> **机器人从实际接触与交互经验中，认识当前身体—环境怎样相互作用、在明确条件下有哪些联合行动可能，以及怎样改变身体与接触使后续条件更适合目标；利用这些认识形成、执行和修正行为，并由真实反馈持续更新。**

目标不是只识别地面、预测摔倒、维持站立或训练一个更强行走策略。任务名称可替换，物理需求与独立验收不能省。**主体研究完整考虑合理信息，消融负责归因**；不改成最小传感器筛选，不先证明不可替代或设置一次“杀死课题”的统一门槛。

| 三部分当前组织（非固定章节／网络） | 主要研究内容 | 关键边界 |
|---|---|---|
| **I：足地接触感知与当前联合能力认知** | 实际承载、剪切、卸载、足部运动与历史；结合身体、负载及执行条件形成运动—作用—支撑的联合可能、限制与未知 | 环境感知与能力合在I；“火柴人”、整体近似、共享“口诀”和按需读取保留。能力不是地形标签／总稳定分数，也不只由足底产生。模式、响应与时间需明，旧固定落足定义不自动覆盖全部行走。 |
| **II：身体—接触调整的能力变化与改善认知** | 调整如何改变接触、后续能力及过程代价；为目标求合适身体、载荷、持物、足姿或落脚条件和到达方式 | 恢复完整“如何改善”，前向后果与目标求解互补；不只挑最高分姿态，不强制独立世界模型。不能冻结当前足底图、任意指定未知支撑或只看终点。 |
| **III：认知驱动的全身行为形成与闭环适应** | 将目标与两类能力认识共同用于身体、双足、持物／末端配合，在接触接替及预测偏差下实际执行和反馈修正 | 不只给另一套既定动作提建议，也不只将抽象姿态换关节角；可复用执行工具，不预定原创底层控制，但需全过程任务证据。 |

**三种认知不是三个强拆网络；三部分不是三种任务或三章。**同一任务可贯穿I／II／III，模型、数据与求解可共享，II／III联合设计。I回答允许条件下有哪些实现可能，II回答具体改变会怎样、怎样更合适，III回答如何真实做到并修正；不按动作大小、速度或毫秒数分界。已由I包含的微调被执行，不重复计作新能力扩大；II也不必等I说做不到才启动。

**表示与更新：**保留可用方式、限制、物理余量与认识不确定性；查询不会创造证据。新落脚／变化后承载与到达需依据，触地后重估。持续反馈可多频率，不等于每个电机周期完整推理、不等于持续干预，也不默认在线改权重／终身学习。当前认知不是完整Markov状态，必要速度和历史不得删掉。

**范围与题目：**家庭是工作背景，不是已验证所有家务；不按是否明显走动或步数多少限制方法，也不要求持续边走边操作。固定落脚、局部换位、带载／跨区可按需求研究，需明确覆盖模式、动态范围、动作权限与中断规则；通用导航、所有步态、完整材料辨识与大模型不是主体。最新工作题名建议为**《不确定足地接触下人形机器人能力认知与主动适应研究》**，未正式定案。

**投入与证据：**信息增益、专门能力表示增益、调整后果和闭环使用收益分别比较。实际成功不单独证明三种认知，要有接触参照、同状态未执行需求判断、同起点不同干预后果和独立任务结果。允许无增益与主张修正，不用更极端条件保护模块。原研究原则见9.23，最新三部分详见9.26，II关键接口仍见9.15。

### 3. 支撑、任务、场景与数据：当前工作范围，不是全盘定案

| 主体支撑条件 | 验证重点与现实对应 |
|---|---|
| **普通硬地** | 正常完整支撑与性能代价对照，不让基线故意失败。 |
| **低摩擦硬地及摩擦差异** | 双足同低摩擦、左右不同、普通—低摩擦过渡；瓷砖只是经核验的载体，不默认天然低摩擦。 |
| **轻度可变形铺设** | 地毯／衬垫／家用地垫的有限受载变形；目标载荷下核响应，不预设更软、更慢或更重更有利。 |
| **局部有效支撑变化** | 铺设边缘、接缝、小高差／轻微不平整；跨边界不一定半脚悬空，未加载不等于无潜在支撑。 |

**左右差异与过渡是重点之一：**双足同条件、左右互换的异质条件、单足跨边界；固定落脚的载荷转移；真实重新落脚后的接触接替。普通—低摩擦也是过渡，不只硬—软。先分离因素再组合，不要求每个场景叠加全部困难。活动衣物／多层覆盖物／隐藏硬物为扩展；沙土、碎石、大高差不作为家庭主体，不能以弹簧板冒充所有真实软层机制。

**自然背景：**原有地毯邻近家具的开合／擦拭／取放，原有硬地—地垫操作区，房间交界或收纳箱／衣物篮跨区运输。杂乱可提供整理任务但不是地形；不默认必须踩杂物、长时间踩边界或禁止绕行。应用、变化异常、受控机理实验分别说明；来源真实不等于支撑影响或方法增益已证。

**当前有限验证组合建议：**受控身体调整及表面运动—作用任务族，配合带载跨区与一种家具接触操作（普通拉出式抽屉作为工作实例）；无载跨区／均一地面为对应对照，擦拭可共用机制装置。任务优先级、数量与具体参数未定，不称擦桌或带载已被证明最佳。按资源和准备主张的范围选取，不能为了任务数量扩展完整家务系统。全部任务盘点、真实对应、已撤回推荐与带载×跨区对照见9.25。

**任务规格：**受控实验可固定相容轨迹、作用、时程；应用以开合到位、物品保持与到达、覆盖／清洁等结果为核心，允许预先约定的停顿、换位和重新接触。持续手接触、持续作用、持续任务进度与迈步分别定义。只测力跟踪不叫去污效果，稳定但不前进不叫搬运成功；不事后降任务要求。

**数据主线不变：**保存物理一致的连续轨迹再切历史。交叉覆盖身体、负载、支撑和需求，避免低摩擦总伴大负载等捷径；保留相近当前状态的不同历史及历史不同但能力相近的反例。I用独立当前能力参照，II复用真实转移并补干预／到达／任务数据，III用独立闭环结果；探索不默认部署额外试探。

**公开资源与工程候选保留：**KROCO、HOI-Retarget／OMOMO、OmniRetarget、GRAIL、AMS、AMASS＋BABEL、LAFAN1、GMR和BeyondMimic的角色、字段报告、许可与限制见9.12。公开示范提供需求和参考，不是H2 Plus足底真值或能力标签；不跨库拼接不相容力／运动。平滑命令、双支撑QP／WBC、首版不主动换步、旧时间／作用／60回合数字仍是未验证调试候选，不是本轮新决定，见9.13、9.22。

**正式采数前核清观测身份：**合力、法向、摩擦与分布三维足底不是同物；只读到合量就记录合量，不均分伪造阵列。特权与可用输入、控制失败与数值异常、命令前后及reset分别记；扳手继续力矩在前、力在后。按回合与同源重放／增广分组，避免历史窗口泄漏。

### 4. 第一部分已有架构候选；眼前接入改装模型并验证观测

**用户原始方法思想：**仿真中生成不同地形、外力和轨迹数据，聚类／判别器激励探索，以隐变量或少量共享结构组合形成环境感知与能力认识，参考元学习与物理模型增强。随后用户用“口诀／骨架”强调机制／关系复用，又澄清既要知道哪些联合方式受限，也要知道大致可做的身体—接触—方向—轨迹—作用配合；不是仅学几个不等式。足底区域化是用户候选，但担心丢信息。

**当前首版架构建议（非算法定案）：**逐点足底空间与因果历史先编码，再形成带空间身份的区域特征；结合足端IMU、本体及已执行命令，形成区域／身体特征和当前上下文；以查询相关读取和条件调制的共享关系，表达联合能力、限制与未知。可靠物理结构保留，训练侧另有能力参照、可选特权桥接和探索调度。六区、128维、卷积／注意力、三类关系组、教师或判别器均为助手候选，不必首版一起完成，详见9.19。

**表达与证据边界：**能力对象是当前表示与整个读取函数，不是单个query或一根无用途潜向量。粗粒度可读成带条件的联合片区，但一类中存在可行细化不等于整类都可行；片区跨边界与认识不足不同。姿态／轨迹／力范围不可任意拼接；区域化不等于先求平均；潜变量、求解能量、概率、物理余量与安全保证不同。实际新接触与到达不能凭冻结当前足底分布推出，详见9.16—9.18、9.15。

**尚未闭合的方法核心：**首版联合坐标与未指定身体自由度、允许局部响应及时间、可信能力参照、共享关系的组合方式。聚类／技能不同不等于能力不同，探索轨迹与能力标签分开；单控制器失败不等于物理无解。充分信息下共享结构的表达能力、普通历史的识别能力、未见组合表现分别检验。普通条件网络与共享版本使用相同信息、参照和合理训练机会，信息收益与方法收益分开。无需等待全部算法或成功保证才能开始限定原型，也不能用基座建设替代这些问题。
