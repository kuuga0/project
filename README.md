### 1. 用户研究主线：认识、面向目标求配置、闭环兑现

> **机器人认识现在实际怎样踩住环境，以及在当前条件下还能怎样组织身体、移动末端和施加作用；根据任务需要，寻找更合适的身体与接触条件；再通过全身闭环控制，把末端运动和交互作用共同实现。**

目标不是只识别地面、预测摔倒或维持站立，而是在不确定足地接触下把任务做好，同时满足约定安全条件。**主体研究完整考虑合理感知与机制，消融负责归因**；不改成最小传感器筛选，不把先证明不可替代或一次“杀死课题”的实验当成开展研究的门槛。信息／方法收益均待验证，一般工况可以没有增益。

|---|---|---|
| **I：当前环境接触感知与联合能力认知** | 实际怎样承载、剪切、卸载及运动；从当前身体、接触与历史出发，允许规定局部适应时，身体构型—末端运动—交互作用有哪些联合实现可能性？ | 用户提出共享结构与粗粒度能力方法思想；已有分层感知、共享关系、当前调制与联合读取架构候选。可用方式、限制、未知并存，不只学禁止区；具体坐标／监督／组合未定，非冻结身体或足底独立给能力。 |

**第一、第二部分不按小动作／大动作划分。**I认识允许响应内的实现可能性；II按目标求具体合适条件及调整方式。同一个微调可以涉及两部分，但已被I包含的可能性被执行，是兑现／降代价，不重复计算为新增原能力。II不必等I说做不到才启动；“能做但吃力／不利后续／认识不足”也可比较配置。统一需求、评判尺度与总时间预算，执行后用新观测重估，不把预测当事实。

**你的原始想法仍在：**身体—末端—作用联合关系；“火柴人”式构型直觉；高维坡面和整体近似认识；具体需求读取同一对象、不自动增加证据；通过连续交互与已执行历史学习，部署时不默认必须额外试探。场、集合、概率和排序是表示候选；物理余量、实际风险和认识不确定性分开。I、II、III区分问题与证据，不强拆网络、训练或求解器，也不平均分配创新；旧“最终选择主要归III”不限制II目标配置思路。共享“口诀／骨架”、能力与限制、粗粒度语义和区域化见9.16—9.18；架构见5.5.1、9.19，II接口见9.15，原能力讨论见9.9—9.11；最新研究组织见9.23。

**投入与证据原则：**区分核心方法、必要工程和实验分析。用合理现成方案替代拟新增机制后，还有什么重要判断／执行缺口，是研究投入的依据；不是删除功能让系统失效后证明它“必须创新”。新增足底信息的收益与专门能力表示的收益分别比较，II／III仍需独立任务结果。每个核心章要推进论证，但不必各提新算法；系统实验章应有对照、归因、泛化和失败分析，而不是演示汇总。本校与导师的具体章节要求本轮未取得，不作毕业达标保证，也不成为模型检查前置门槛。

范围仍主要指操作中的局部身体移动、载荷转移、足姿及必要单步／少量换步，不要求长距离导航，也不永久固定双脚。正式题目、动作权限、最终应用及具体方法未定。

**公开资源可提供两类输入：**从交互示范提取需求结构、路径／作用与时程；从动作库取得身体协调参考和探索种子。KROCO、HOI-Retarget／OMOMO、OmniRetarget、GRAIL、AMS、AMASS＋BABEL、LAFAN1、GMR与BeyondMimic等入口、字段报告、许可与限制保存在9.12。前序及本聊天均未新增这些资源已下载运行或选定使用的报告；公开动作不等于H2 Plus足底数据、动力学可行证据或能力标签，不能跨库拼接不相容力与动作。

**任务候选：**保持接触的末端表面运动—施力作为共同机制任务族，系统改变路径、作用和时程；开门、阀门、安全工具／表面作业、推拉及可选带载泛化仍保留。用户没有定最终清单；一个任务族不等于一条擦拭演示，也不限制基础探索只能采任务成功轨迹。

**支撑候选：**完整刚性、部分／边缘／不对称支撑、受控摩擦差异、可控柔顺／刚—软不对称。沙土和自然地面需单独明确颗粒、沉陷或混合机制，不用弹簧软板冒充真实沙地，也不预设更软、更慢或载荷更多一定更好。具体实现与反例见9.11、9.13.5。

**开发建议的身份：**共同工程包含本体、场景、观测、基础执行、任务／探索与记录评价；平滑命令先于大型探索策略，身体／载荷目标需考虑冲突。双支撑QP／WBC、切向运动＋法向力、首版不主动换步等都是候选，不是用户已定路线。1秒建立作用、4秒走10厘米、$0.03mg$、60个回合等只保留为未验证的仿真调试示例，非H2 Plus规格或实机参数。详见9.13。

### 4. 第一部分已有架构候选；眼前先建最小基座

**用户原始方法思想：**仿真中生成不同地形、外力和轨迹数据，聚类／判别器激励探索，以隐变量或少量共享结构组合形成环境感知与能力认识，参考元学习与物理模型增强。随后用户用“口诀／骨架”强调机制／关系复用，又澄清既要知道哪些联合方式受限，也要知道大致可做的身体—接触—方向—轨迹—作用配合；不是仅学几个不等式。足底区域化是用户候选，但担心丢信息。

**当前首版架构建议（非算法定案）：**逐点足底空间与因果历史先编码，再形成带空间身份的区域特征；结合足端IMU、本体及已执行命令，形成区域／身体特征和当前上下文；以查询相关读取和条件调制的共享关系，表达联合能力、限制与未知。可靠物理结构保留，训练侧另有能力参照、可选特权桥接和探索调度。六区、128维、卷积／注意力、三类关系组、教师或判别器均为助手候选，不必首版一起完成，详见9.19。

**表达与证据边界：**能力对象是当前表示与整个读取函数，不是单个query或一根无用途潜向量。粗粒度可读成带条件的联合片区，但一类中存在可行细化不等于整类都可行；片区跨边界与认识不足不同。姿态／轨迹／力范围不可任意拼接；区域化不等于先求平均；潜变量、求解能量、概率、物理余量与安全保证不同。实际新接触与到达不能凭冻结当前足底分布推出，详见9.16—9.18、9.15。

**尚未闭合的方法核心：**首版联合坐标与未指定身体自由度、允许局部响应及时间、可信能力参照、共享关系的组合方式。聚类／技能不同不等于能力不同，探索轨迹与能力标签分开；单控制器失败不等于物理无解。充分信息下共享结构的表达能力、普通历史的识别能力、未见组合表现分别检验。普通条件网络与共享版本使用相同信息、参照和合理训练机会，信息收益与方法收益分开。无需等待全部算法或成功保证才能开始限定原型，也不能用基座建设替代这些问题。

**眼前最小基座的完成标准：模型可用、交互可重复、数据可回读。**先读现有H2资产、核H2 Plus对应并加载；再在简单支撑下形成基础控制的站立／有限身体与载荷变化，连续保存接触、本体、执行命令和时间并回读。只有合量就如实记录合量；直接改姿态、隐藏支撑或均分合力不能冒充真实交互／阵列。

|---|---|
| 1. 模型—观测—记录 | 加载并核实际模型、碰撞／末端；取得真实观测样例和一条可回读记录。 |
