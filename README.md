## 当前研究

用户明确希望机器人获得**环境接触感知、能力认知和如何改善的认知**，并利用这些认识形成、执行和修正行为，由真实反馈持续更新。目标包含任务完成，不限于地形识别、摔倒预警或保持站立；也不预设只能给另一套现成控制系统提供建议。

主要背景是家庭既有铺设，主体条件为普通硬地、低摩擦及摩擦差异、轻度可变形铺设、局部有效支撑变化；左右足不同和支撑过渡是重点之一。接触操作、带载移动和跨区域行走是互补验证候选，具体主任务、材料、动态范围、算法及正式题目尚未定案。工作题名建议为《不确定足地接触下人形机器人能力认知与主动适应研究》。

| 当前组织建议 | 要回答的问题 | 方法状态 |
|---|---|---|
| I：足地接触感知与当前联合能力认知 | 当前实际怎样接触，在明确模式、允许响应和时间条件下有哪些身体—支撑—运动—作用联合可能、限制与未知？ | 当前优先。已有分层接触／历史编码、共享关系和按需求读取的架构候选；表示、能力参照及组合机制仍需比较。 |
| II：身体—接触调整的能力变化与改善认知 | 改变身体、载荷或接触后会怎样，怎样更适合目标，过程和到达是否可行？ | 保留前向后果与目标导向求解，不只选择最高分姿态，不强制独立世界模型。 |
| III：认知驱动的全身行为形成与闭环适应 | 怎样把认识用于真实动作，并在接触接替与预测偏差下执行、反馈和修正？ | 与II联合设计；可复用执行工具，最终需独立全过程任务证据。 |

用户已确认“完整闭环、集中核心研究、不为章节强造创新”。三部分不等于三个网络、三种任务或三个必须独立创新的章节。主体研究完整考虑合理信息，再以消融分别判断信息、表示、调整后果和闭环使用的增益；允许无增益及修正主张。

已有单足集合是理论／数字基线，G1旁路是信息结构与离线分析基础；二者不能直接证明H2 Plus联合能力、真实FOOTRIX效果或闭环任务收益。当前未承载不等于无潜在支撑，三轴力不直接给摩擦极限，IMU不直接给接触力；查询不能创造证据，冻结当前接触也不能证明新配置可达。
