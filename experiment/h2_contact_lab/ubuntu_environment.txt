H2 Plus Isaac Lab 环境说明
==========================

用户现有 Ubuntu 环境已经包含采集器需要的运行时。此前记录的版本为 Python 3.11、Isaac Lab 2.3.2、Isaac Sim 5.1.0 和 PyTorch 2.7.0+cu126；本轮未重新连接 Ubuntu 核验。

本项目在 Isaac 环境之外只用 Python 标准库，没有额外 pip 依赖。`requirements.txt` 因此保留为注释说明，没有可安装的包；已有环境直接激活即可，**不需要运行 pip install -r 来重装 Isaac**。

只有新建运行环境时，才需另按 Isaac Lab／Isaac Sim 对应版本的官方流程安装完整运行时。Ubuntu、NVIDIA 驱动、CUDA runtime 和 GLIBC 等系统条件不属于 pip requirements。

使用现有环境运行前，确认其 Python、Isaac Lab、Isaac Sim 和 PyTorch 版本匹配，并且可以正常启动 PhysX。
