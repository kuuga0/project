# 传感信息对比报告：原足8×4

> 保存结果说明（2026-10-25核对）：本页属于原足8×4的uniform-speed批次，数据和原统计数字保留，本次未重跑。模型与批次见 [本单元说明](../../README.md)；不能与rough 20回合或其他网格的数据混用。

本报告由 `analyze_sensor_information.py` 根据同一批行走轨迹生成。宏观基线是双脚踝部六维接触扳手与 CoP；扩展输入依次加入足底 `8×4` 单元的三维力和踝部 IMU。

## 数据规模

- 采样行数（降采样后）：`480`
- 特征维数：宏观 `16`，足底阵列 `192`，IMU `12`
- 各地形行数：`{'rough': 160, 'slope2': 160, 'stairs': 160}`
- 有接触的足-帧数：`575`；每只脚平均非零单元数：`2.69`；平均超过 1% 载荷阈值的单元数：`2.65`

## 结果一：宏观量相近时，阵列/IMU 仍然不同

对每一帧，寻找另一种地形中宏观特征最接近的帧，再比较完整传感特征。宏观近邻的归一化距离中位数为 `0.2724`；同一对样本的阵列+IMU 距离中位数为 `0.2747`，比值为 `1.01`。这是本批次两个特征空间中的标准化距离描述；维数与尺度不同，不能仅凭中位数或比值推出普遍信息增益。

## 结果二：宏观量的线性重建误差

用留一组（地形+episode）交叉验证，以宏观量线性预测所有阵列单元三维力，归一化 RMSE 为 `5.6261`，未解释比例约为 `100.00%`。这是该线性模型、分组与归一化方法下的残差，不能证明所有非线性方法均无法重建。这里“未解释比例”由脚本将归一化RMSE的平方截断到1得到，不是互信息或严格的方差解释率。

## 结果三：地形区分能力

用“地形＋episode”分组留出后的最近质心分类作离线比较：

|输入 |准确率|
|---|---:|
|踝部六维扳手 + CoP|54.17%|
|足底阵列 + 踝部 IMU（不含宏观量）|57.29%|
|宏观量 + 足底阵列|56.25%|
|宏观量 + 足底阵列 + IMU|59.38%|

这个分类器只是验证“是否存在可区分信息”，不是最终的地形识别器。真正的边界更新还需要下一步定义接触约束/不确定性集合，并用外力扰动或多种落足姿态做独立验证。

## 解释与限制

当前阵列是基于 MuJoCo 解算接触点位置和三维接触力的虚拟旁路传感器；它没有把几何单元直接宣称为真实压力阵列，采集器未修改候选模型的碰撞几何，也未把新增观测反馈给策略。其价值是先验证信息结构：宏观扳手与 CoP 只保留总力和一阶力矩，阵列保留了多单元载荷分配、切向力分配、接触单元数量等高阶信息，IMU 还提供了足部运动状态。进一步结论需要带有限感知区域的物理足部模型、独立接触参照、可控扰动和更多回合。
