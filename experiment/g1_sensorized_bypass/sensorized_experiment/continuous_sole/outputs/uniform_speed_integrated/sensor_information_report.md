# 传感信息对比报告：连续足板8×4

> 保存结果说明（2026-10-25核对）：本页属于连续足板8×4的uniform-speed批次，数据和原统计数字保留，本次未重跑。模型与批次见 [本单元说明](../../README.md)；不能与rough 20回合或其他网格的数据混用。

本报告由 `analyze_sensor_information.py` 根据同一批行走轨迹生成。宏观基线是双脚踝部六维接触扳手与 CoP；扩展输入依次加入足底 `8×4` 单元的三维力和踝部 IMU。

## 数据规模

- 采样行数（降采样后）：`453`
- 特征维数：宏观 `16`，足底阵列 `192`，IMU `12`
- 各地形行数：`{'rough': 133, 'slope2': 160, 'stairs': 160}`
- 有接触的足-帧数：`578`；每只脚平均非零单元数：`2.98`；平均超过 1% 载荷阈值的单元数：`2.96`

## 结果一：宏观量相近时，阵列/IMU 仍然不同

对每一帧，寻找另一种地形中宏观特征最接近的帧，再比较完整传感特征。宏观近邻的归一化距离中位数为 `0.2479`；同一对样本的阵列+IMU 距离中位数为 `0.2355`，比值为 `0.95`。这是本批次两个特征空间中的标准化距离描述；维数与尺度不同，不能仅凭中位数或比值推出普遍信息增益。

## 结果二：宏观量的线性重建误差

用留一组（地形+episode）交叉验证，以宏观量线性预测所有阵列单元三维力，归一化 RMSE 为 `15.3340`，未解释比例约为 `100.00%`。这是该线性模型、分组与归一化方法下的残差，不能证明所有非线性方法均无法重建。这里“未解释比例”由脚本将归一化RMSE的平方截断到1得到，不是互信息或严格的方差解释率。

## 结果三：地形区分能力

用“地形＋episode”分组留出后的最近质心分类作离线比较：

|输入 |准确率|
|---|---:|
|踝部六维扳手 + CoP|55.41%|
|足底阵列 + 踝部 IMU（不含宏观量）|64.46%|
|宏观量 + 足底阵列|64.24%|
|宏观量 + 足底阵列 + IMU|64.02%|

这个分类器只是验证“是否存在可区分信息”，不是最终的地形识别器。真正的边界更新还需要下一步定义接触约束/不确定性集合，并用外力扰动或多种落足姿态做独立验证。

## 解释与限制

本批次使用添加连续足板后的G1模型，足部碰撞几何已改变；策略没有接收新增观测。阵列仍是MuJoCo接触样本的虚拟积分分区，不是实体传感器。其价值是先验证信息结构：宏观扳手与 CoP 只保留总力和一阶力矩，阵列保留了多单元载荷分配、切向力分配、接触单元数量等高阶信息，IMU 还提供了足部运动状态。连续足板仍不等于真实触觉硬件；进一步结论需要独立接触参照、可控扰动、更多回合和实际干预验证。
