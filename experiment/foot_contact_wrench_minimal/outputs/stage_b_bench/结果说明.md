# 阶段B基础台架结果说明

> 2026-10-25核对说明：本目录保存前期单足MuJoCo基础工况，本次未重跑仿真。入口见 [脚本目录](../../docs/script_catalog.md)，其他边界／部分支撑／融合工况在各自结果目录，不与本目录混用。

本工况为4 kg自由刚体足，按当前保存配置以零速度水平贴合初始化。0.20×0.10 m足底对应10×5共50个20 mm有限面积理论单元，数字模型在单元中心使用点接触近似。保存的 `contact_truth.jsonl` 共750行、至约1.5 s；末态法向合力约39.24 N，对应足体重力。

| 文件 | 实际内容 |
|---|---|
| `bench_contact_wrench.png` | 合力、合力矩时间序列和末态50点法向载荷图。 |
| `theory_simulation_comparison.png` | **合力／合力矩大小及末时刻三维方向**的比较；不是六分量上下界图。接近零的合力矩方向未定义。 |
| `wrench_comparison.csv` | 六分量真值、法向代理重建及误差时间序列。 |
| `wrench_comparison_metrics.json` | 力矩在前、力在后的分量顺序／单位、理论轴向上下界和各分量RMSE。 |
| `contact_truth.jsonl` | 约束接触、50点法向代理、完整接触扳手及足部运动状态。 |
| `summary.csv` | 便于绘图的扁平化时间序列。 |

MuJoCo完整接触扳手与法向压力代理来自同一批接触约束。约机器精度的重建误差说明本对称静止工况下的提取／合成一致性，不能证明真实压力阵列精度，也不表示只测法向即可在一般运动中重建完整六维扳手。

交互查看器中的红／橙为MuJoCo完整扳手，蓝／青为法向代理，绿／紫为固定39.24 N截面上的多个支持查询见证。当前代码按多个合力／合力矩方向采样，每个见证保留完整六维扳手；不是仅六根轴向边界箭头。所有扳手参考点均为足部质心，不能跨见证任意拼接力和力矩，也不能把三维箭头包络当作六维集合的等价表示。
