# 阶段A结果说明

> 2026-10-25核对说明：本目录保存前期单足数学查询结果，本次未重新运行求解器。入口见 [脚本目录](../../docs/script_catalog.md)。这些是指定约束下的理论计算，不是传感器采集或H2 Plus结果。

本算例把0.20×0.10 m足底划为10×5共50个边长20 mm的有限面积单元，每单元法向上限98.1 N；固定总法向载荷400 N，50点均分8 N。该400 N是查询截面，不是机器人最大承载能力。

| 文件 | 内容 |
|---|---|
| `baseline_projections.png` | 切向合力及滚转／俯仰力矩平面的集合投影；蓝色为约束下的投影，橙色为均匀载荷工作点。投影中的各点不能跨维度任意拼合。 |
| `contact_grid_layout.png` | 50个有限面积单元的位置与编号。 |
| `support_queries.csv` | 六个扳手坐标正、负方向的支持查询。 |
| `radial_queries.csv` | 从当前工作点沿六个正方向到边界的径向查询。 |
| `working_point.json` | 配置路径、接触位置、单元面积／上限、当前法向载荷和工作扳手。 |
| `plot_metadata.json` | 绘图参数和投影说明，结合图像阅读。 |

六维扳手按 `[tau_x, tau_y, tau_z, f_x, f_y, f_z]` 排列，参考点为足部质心；当前工作扳手约为 $[0,0,0,0,0,400]$。改变载荷或摩擦条件需要重新求对应集合，不能直接沿用这一个截面。
