# 研究主文档

基于高价值选读整理的首版研究正文，非全量覆盖，不代表所有历史方案已获用户确认。文中的路线评议、文献转述与实现报告保留其来源身份；本轮未作独立文献核验、工程复现或实测验证。

## 一、主要候选研究方向：接触条件下的物理能力

前三批及新增自写资料中的路线评议认为，单纯研究“压力阵列识别接触、CoP 或部分落足”不足以承担课题核心。这些来源提出：足底感知不是人形机器人基本运动的必要模块，复杂地形行走也可以依赖本体感知、视觉或学习策略完成；压力加 IMU 作为多模态输入也已有相近路线。上述判断本轮未作独立文献核验。由此形成的主要候选问题是：在人形机器人处于局部、边缘、非理想或不确定足地接触时，如何从多模态接触观测估计当前可用的物理能力，判断动作和外载荷将怎样改变这种能力，并据此调整接触、载荷或任务。[F0001；自写《足底感知项目全量内容整理》“最终研究定位”“领域复核”]

来源提出，足底阵列值得检验的观测增量主要是接触场信息：实际承载区域、压力分布、接触拓扑和演化，而不是直接提供完整六维扳手。它应被定位为高信息量观测手段之一，可与踝部 F/T、本体、足端 IMU、视觉或其他接触估计器比较；课题成立不应依赖“足底不可替代”这一前提。[第三批 S1；自写《阶段总结》]

## 二、必须分开的对象：实际扳手、观测一致性与能力边界

当前最重要的理论澄清是，不要把“此刻产生了什么力”与“在当前接触条件下还能提供什么力”合并。可按层次保留以下对象：

1. **动力学扳手集合**：由整体动力学、状态和上游外力约束当前地面合扳手；状态和参数有不确定性时它是集合，而非必然单点。
2. **观测一致集合**：压力阵列约束有载荷单元、法向总载荷和 CoP，IMU 约束姿态、加速度、角速度及冲击/边缘旋转等动态状态，再与动力学约束相交，得到与当前观测相容的扳手集合。
3. **局部接触能力集合**：固定接触模式、几何、摩擦和总法向载荷，允许重新分配各接触单元力，得到足地可以提供的局部扳手集合。
4. **整机与时间层集合**：加入双足分配、关节/执行器和全身动力学后，才谈瞬时整机可行集合；再向有限时间的动作可达、可生存/可恢复和任务允许集合扩展。

压力与动力学的交集不能直接被称为能力：交集回答“哪些扳手与当前观测相容”，能力集合回答“重新分配后哪些扳手可实现”。同样，支持函数、方向投影和从工作点沿加载方向的径向能力是不同查询；力和力矩混合时还要先做量纲归一化。[第一批；自写《理论模型》]

**正文使用边界：**本稿尚未收录局部集合的完整数学定义、支持函数与径向查询的具体公式及坐标/归一化约定。进入相应推导或代码复现时，需针对性核对已引用《理论模型》的相关内容并补入必要定义；不能把本稿当作完整复现说明，也不能凭常识补写后声称是旧方案。此缺项不阻塞其他整理工作。

单足实验的科学位置因此是模块边界和基线：先在固定接触模式与载荷截面验证局部集合、观测一致性和能力边界，再把变量映射到双足支撑切换、全身耦合、质心运动和任务约束。单足结果不能直接证明双足稳定或整机任务成功。[第二批；自写《足底感知项目全量内容整理》“单足是可验证子问题”]

## 三、观测模型的能力与硬边界

压力阵列可以在标定后给出法向载荷、承载区域和 CoP，但切向合力、偏航力矩、摩擦系数和完整六维扳手通常不可由法向压力唯一恢复。缺少足够切向激励时，观测至多说明实际切向力满足摩擦不等式，不能辨识摩擦极限；学习到的地面先验不能替代证据。主动小激励可作为后续研究，用于区分边界和检验支撑，但其是否被正式采用尚未确认。[第三批 S1；第一批 F0002–F0004]

足端 IMU 可用于坐标变换、动态状态和动力学约束。若足部刚体质量、质心、惯量及踝部/上游扳手已知，动力学关系可辅助估计接触合力；若上游外力未知，IMU 只看到所有外力的合效应，不能单独把地面力分离出来。安装点偏置、角加速度、离心项、姿态误差、求导噪声和软层变形都会限制精度，不能把 IMU 当作剪切力传感器。[第三批 S1；自写《理论模型》]

微滑移也不能直接等同于变形、撕裂或整体打滑。粘着区可有内部剪切变形而不发生界面相对运动，滑移区才有相对地面的切向位移；边缘先滑是柔性接触中的示例，不是所有接触的必然顺序。局部移动还可能来自正常载荷重分布或滚动，因此必须有独立真值和受控对照，不能只凭压力图或 CoP 变化下结论。[第三批 S2]

采集系统本身可能制造假状态变化。响应时间、稳定时间和真实物理带宽不是同一概念；逐点蠕变、历史加载、串扰、机械贴合和滤波会使恒载下 CoP 漂移。压力与 IMU 必须统一时间戳，并实测同步误差、丢帧、输出率和滤波延迟，否则无法可信地讨论事件先后、提前量或“预测”。建议以独立六维 F/T 作为离线对照真值，分别比较压力单独、压力加 IMU、三轴触觉及其融合的增量；当前材料没有证明这些标定、同步和对照实验已经完成。[第三批 S3；F0005–F0011 中嵌入研究段]

## 四、实验与仿真应形成分层证据链

本轮选读的自写资料报告：单足离散接触模型、局部接触扳手集合、支持函数/径向查询以及数字接触台、理想压力与 IMU 融合测试已形成；同时记录了 G1 虚拟足底旁路的多地形离线结果。上述完成状态属于资料报告，本轮未独立复现或实测核验。资料将这些工作置于 L1–L3：理论、数字接触和理想观测，不能据此提升为真实 Footrix 硬件、真实传感器误差、X1 整机或闭环任务结果。真实压力/触觉实验、独立真值、双足分配、未来支撑预测、MPC/WBC 闭环及失败率下降仍未被本轮材料核验；未获本轮核验不等于整个课题从未开展这些工作。[自写《足底感知项目全量内容整理》“可信度层级”“完成度”]

实验路线应从可复现局部问题开始：固定接触区域和总法向载荷，改变支撑几何、足姿、CoP 和外载荷，检验局部能力边界及其与压力/IMU 观测的对应关系。正式动态候选是触地、承重和 foot-flat 的早期支撑相，采用小预载、弹簧—阻尼短行程等受控加载；手轮适合标定，不应被写成正式动态验证。所有载荷数值仍是待标定参数，不能冒充实验事实。[第一批；F0001]

通过后再扩展到双足接触切换、载荷分配和全身任务。高层验证必须问清局部指标是否预测任务表现，而不是把一次成功演示写成普适稳定保证。若要研究动作条件化支撑演化，应设置冻结模型与 Oracle 对照：如果知道未来接触并不能明显改善决策，预测主线就缺少必要性；若差异稳定存在，才有理由研究有限时间的能力转移和可恢复性。[自写《足底感知项目全量内容整理》“Oracle–Frozen 对照”]

## 五、从能力边界到动作和任务决策

已有材料提出一条比“感知—控制接口”更有研究意义的链条：

`真实接触与不确定性 → 当前观测一致性 → 任务相关能力 → 动作条件化能力变化 → 任务保持与主动调整`。

“现在能做”不等于“做完以后还能恢复”。因此应区分瞬时可行、有限时间动作可达、短时可生存/可恢复以及满足手端和身体任务约束的集合。若任务需求与保守能力域没有交集，机器人可以改变 CoP、足姿、载荷分配、重新落足、增加手/环境接触、修改任务或安全停止。这里的“环境利用”不是泛泛具身智能，而是把真实接触转成可查询的物理可供性。[第二批；自写《足底感知项目全量内容整理》“Observe–Understand–Interact”]

主动小激励应保持为待证分支：轻触、微小踝滚转或载荷转移可能提高接触边界可辨识性，但必须证明它带来比被动观测更好的决策，并量化对安全、时间和任务扰动的代价。不能因为概念合理就写成已完成控制策略。[第三批 S1；F0001]

## 六、当前可保留的候选定位与待确认问题

目前保留、尚待用户确认的候选研究定位是：**不确定接触条件下的人形机器人物理能力感知、预测与主动调节**；足底感知是观测模态之一，单足台架负责验证“真实接触观测→局部物理能力表征”。不宜把题目收缩为单足传感器、CoP、部分落足分类或“压力输入使行走更稳”。

仍影响研究判断的关键问题有三类：其一，压力/IMU 相对强本体或踝部 F/T 基线的可复现增量；其二，漂移、正常载荷转移、变形与真实微滑移的可分性；其三，冻结模型与动作条件化预测是否在受控任务中产生可测差异。以上均需真实数据和独立真值支撑，当前材料没有把它们报告为已完成。
